# V0.4 世界索引

## 目标

为每个章节提供可审计的世界/卷归属，供世界名称明确的查询执行向量检索过滤。

## 构建

```powershell
python scripts/build_world_index.py --project reincarnation_paradise
```

也可以在前端的“数据索引”页点击“构建世界索引”，或调用：

```text
POST /api/projects/{project_id}/worlds/build
```

## 产物

- `data/{project_id}/worlds.jsonl`：候选世界的名称、章节区间、边界证据、置信度和状态。
- `data/{project_id}/chapter_world_map.jsonl`：每个有效章节的 `world_id` 映射。
- `data/{project_id}/world_index.json`：按名称和章节的快速索引。

## 边界规则

第一版仅接受同时具有系统提示格式和“世界难度/世界之源”字段的进入事件。返回边界要求结算提示中同时出现“衍生世界”和“综合评价/结算”。无法可靠提取世界名称时，记录为“未命名世界候选”，不参与查询过滤。

这些记录均标为 `candidate`。它们是后续人工校正和模型复核的输入，而不是不可变的事实。

## 查询行为

问题中精确包含已命名世界时，系统从更大的向量候选池中只保留该世界的章节；普通问题仍使用全局检索。调试信息会展示匹配的世界，命中片段会显示其世界归属。
